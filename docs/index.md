# IGT Model Comparison

This project compares the Q-learning and PVL-Delta computational models using
data from the Iowa Gambling Task.

## Project components

The project includes:

- preprocessing of the original IGT dataset;
- implementation of the Q-learning and PVL-Delta models;
- initialization of model parameters;
- fitting models to participant choices;
- comparison of model-fitting results.

## Documentation structure

The [**Models**](models/index.md) section explains the mathematical and theoretical definitions of
the models.

The [**API Reference**](api/index.md) section is generated from the Python source code,
signatures, type annotations, and docstrings.
